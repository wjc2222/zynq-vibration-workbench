## 交互摘录的真实性与公开范围

公开精选包含 **6案、29条原文摘录，来自28条不同的用户可见消息**。保留用户要求、助手早期错误或不完整判断、后续纠正及尚未闭环的边界；没有补造对话。编辑摘要单独标注，不能作为历史原话引用。历史助手测量陈述仍须与独立工程证据对照。

JSONL保留原可见消息SHA-256、摘录SHA-256、代码点偏移和省略标志。为公开发布移除了私有会话/消息ID、原日志行号/序号和时间等元数据，以集合内`message_ref`及相对顺序`chronology_index`代替。详细变换和校验口径见[llm_provenance.json](llm_provenance.json)。原始完整私人日志、内部推理、系统/开发者指令、工具记录和附件不随仓库发布。
