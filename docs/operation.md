# 采集与板端训练流程

1. 确认接线、采样率和每转脉冲数。新装置先用已知信号验证通道、幅值、频率和保存文件连续性；确认完成后再接机械信号。
2. 在采集页选择本次工况：正常、不平衡、不对中、松动。输入标签代表操作者已经确认的实际状态，程序不会凭文件名替用户确认。
3. 设置定时/连续采集、目录及文件保存参数。采集时原码保存到SD，停止后等待写入完成；需要固定显示幅值时设置纵轴量程。
4. 保留每次独立机械设置产生的完整文件及meta/labels；同一会话切成多个文件仍属于一次试验。记录安装、传感器及接线条件有助于复验，但不需要人工输入转速或损伤程度作为分类标签。
5. 检测页进入参考样本库，加入四类完整标注记录，确认来源，点击训练/更新模型。训练在ARM执行，保留模型、来源清单、配置与验证结果。
6. 用新采集的独立记录检查四分类结果。训练回放只说明功能流程可执行，不能计算独立测试准确率。显示模型得分也不是经过概率校准的可信概率。

生产算法提取69维并选42维时域/频域特征，32棵树、最大深度3。训练按会话管理权重及分组，避免同一次采集的相邻窗口泄漏到训练和验证两侧。当前不按RPM匹配基线；传感器幅值、安装条件、转速变化仍可能影响分布，需要独立试验验证泛化。

本源码仓库不附实际机械数据或训练模型。使用者需采集并标注自己的数据，通过独立试验评估识别结果。硬件部署依据目标板身份、SD分区和匹配驱动/FPGA版本单独安排，历史板卡脚本不作为默认安装入口。
