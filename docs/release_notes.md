# 首次源码发布说明

项目：`zynq-vibration-workbench`。项目原创部分采用 MIT，已有 GPL/LGPL/BSD 等组件声明继续适用，见 [许可说明](../license_status.md)。远程发布状态以实际仓库和提交记录为准。

本项目提供三路振动原码采集、SD 连续分段保存、Qt/串口交互、PL FIR 与 FFT 计算及 ARM 四分类现场训练。重点是可复现的现场标注、训练与检测流程，分别管理原始数据、预览与分析输入。

源码范围包括 C++/Python/RTL/Tcl、单元与接口测试、Skill 和构建说明。实际机械样本、已训练模型、厂商手册、个人运行记录、SDK 及固件二进制不随本次提供。有效采集逻辑保留原工程贡献来源，第三方文件保留原许可头和文本。

验证状态与范围见 [validation.md](validation.md)。发布检查应绑定最终源码清单；Linux 全系统从零重建和当前 PC 独立依赖锁仍有后续工作。机械故障精度须由独立会话/装配试验报告，不能使用训练回放截图替代准确率。
