# 可迁移的 PS 特征、模型与独立验证

适用于分类、回归和异常检测，不要求特定特征数或随机森林。
先确定真实观测单位和可验证任务，再选择特征与模型。
输入可以来自振动、电流、声学、图像或其他来源，但单位/schema必须显式定义。

## 输入与输出契约

输入：数据清单、标签定义、采集/预处理配置、独立组定义和任务指标。
输出：数据审计、预先确定的划分、训练制品、独立评估与部署兼容信息。
使用 [experiment-plan.json](../templates/experiment-plan.json) 记录实验计划。
该文件是人工规划契约，不是模型训练器配置，也不能直接当作数据审计器输入。
自动审计器的实际输入与命令见 [portable examples](../examples/portable/) 和其 `--help`。

| 元数据 | 用途 |
|---|---|
| sample/record id | 唯一标识，不从文件显示名推断类别 |
| source kind | measured/synthetic/replay/derived 的来源说明 |
| session/group | 共同采集或共同装配相关性，防止跨折泄漏 |
| raw SHA 与区间 | 查副本、重叠窗、同源转换及标签冲突 |
| label 与来源 | 人工确认、诊断或测量依据，以及未知标签 |
| setup/config | 设备、安装、工况、单位、采样与处理版本 |
| split | train/validation/test 或预定义折，划分在拟合之前 |

没有真实标签来源时，不把猜测标签包装成监督真值。
有真实 ADC 字节也不自动等于确认机械来源、标定或故障类别。

## 先定义独立性

连续记录分段通常仍属同一 session。
同一原码裁切、重采样、增广或改名副本必须保留共同来源关系。
需要跨安装泛化时，以安装/机器为更高层组；仅 session 隔离可能仍不足。
需要跨时间预测时按时间先后留出，避免未来统计泄漏。
多层相关性可使用 compound group 或外层留机器、内层留 session。
组数不足以满足每类划分时，报告不足，不强行随机拆窗。

先固定划分，再拟合 scaler、插补、特征筛选、降维、阈值和模型。
超参数选择只能使用训练/验证；最终测试仅用于事先定义的评估。
所有从数据学出的预处理都属于模型管线，不能在全数据上先运行。
调参反复查看最终测试后，应承认其已参与开发并另备独立留出。
分组不会修复错误标签或来源不代表目标域的问题。

## 数据审计不等于训练和精度验证

审计至少覆盖：
- id、标签、source kind 和 group 是否完整且可解释。
- 同一组是否跨 split，同源区间是否重叠或重复。
- 相同字节是否有不同标签，相同标签是否只是文件名派生。
- 各类的独立组数、记录数、时长和任务域覆盖。
- 非有限值、缺失特征、坏 CRC、不连续、削顶等质量事件。
- 合成、回放和真实来源是否被混报为同一效果。

元数据审计器只检查提供的清单及已实现规则，不验证传感器物理真实性。
SHA 一致能发现字节副本，SHA 不同不能证明两个记录独立。
未提供时间区间、父来源或装配信息时，相关风险仍是未知。
保留审计失败并修正数据/划分；不要通过删除不利记录美化结果。

## 由任务选择模型与指标

| 任务 | 先建立的基线 | 需另外说明 |
|---|---|---|
| 多类分类 | 合法常数/多数类与简单线性或树基线 | 每类召回、混淆、类不平衡与未知类 |
| 回归 | 合理常数或简单线性基线 | MAE/RMSE、量纲、误差分布与工况范围 |
| 异常检测 | 仅用允许的正常训练域建立阈值 | 误报率、漏报率、事件聚合和漂移 |
| 神经网络推理 | 主机浮点参考与导出模型 | 张量布局、量化、算子支持和资源 |
| 无足够独立组 | 训练可行性与接口测试 | 不能给独立泛化准确率 |

窗口级与会话/事件级输出分别报告，不挑较好的口径替代原要求。
组内多个窗口不是等量的独立试验；不把窗口总数当独立样本数。
置信区间若使用，重采样单位应匹配独立组，并说明方法和样本限制。
分类器分数不自动是校准概率；阈值需在合法验证集上确定。
转速、设备ID或环境量是否可输入由任务决定，不能照搬本案例门控。

## 模型制品应能被部署端拒绝

至少记录：
`schema_version, feature/tensor names and order, units, preprocessing, model_type`。
再绑定采样/滤波/FFT配置、训练来源清单 SHA、split 定义和训练代码版本。
保存模型参数/权重、合法取值范围及 runtime/ABI 要求。
为模型文件计算 SHA，评估结果必须绑定该 SHA。
签名或可信分发如是任务要求，应另定义机制；SHA本身不证明可信作者。

推理输入缺字段、顺序不符、单位/采样改变或包含非有限值时明确失败。
不能把旧模型重命名成新 schema，也不能仅凭文件能解析就默认兼容。
有意升级 schema 时提供转换、拒绝或重训练策略及回归验证。
模型写入采用平台认可的安全发布流程，保留旧可用模型与恢复路径。

## 在 PS 与 PL 之间移动模型/特征

先固定主机参考和输出度量，再测 ARM/RTOS 或 PL 版本。
量化需要校准集和独立验证；不从测试集反向拟合量化参数。
先比较单算子/中间张量，再比较端到端预测。
固定通道数、布局和窗口长度是某个制品的属性，不是本 Skill 的前提。
更换 RF/SVM/CNN 或回归任务时，重建 feature/tensor schema 与评估计划。
运行耗时包括数据准备、搬运与后处理，不能只用核心推理周期代替。

## 可直接使用的实验提示词

```text
为[任务/类别或回归目标]建立可部署的验证方案。
数据清单：[路径]；来源/单位：[说明]。
独立性层级：[会话/安装/机器/时间]；现有组数：[真实统计]。
可用输入：[特征/张量/合法工况量]；禁止输入：[标签或未来信息]。
目标平台：[CPU/SoC/RTOS/PL]；资源与时延：[约束]。
先审计同源、重叠、标签和跨split问题，按组固定划分；
只在训练折拟合预处理和选择模型，保存schema、来源和模型SHA；
输出每类/事件或回归指标与实际独立组数，列出未覆盖域。
数据不足时只报告训练可行性，不能生成虚构精度。
```

## 失效条件与结论边界

独立组缺失时，最多证明当前数据上的训练与接口可运行。
真实任务域发生改变时，旧验证不能自动延伸到新域。
标签冲突未解决时，不能只通过调模型宣称问题已修复。
合成审计样例能证明检查器行为，不是已训练模型或机械识别效果。
方法来源和当前案例边界见 [evidence.md](evidence.md)。
