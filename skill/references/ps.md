# PS特征、监督训练与推理

先定义类别、观测单位、来源、台架/安装身份和独立会话。人工确认标签是监督真值；待测样本不能把文件名、当前标签、真实类或测试集统计当推理输入。转速等工况是否是合法输入由任务定义决定，不沿用其他项目门控。

连续采集分段属于同一session，改名副本不增加独立样本。用原码/窗口哈希、区间重叠和标签一致性查副本/冲突。先整session划训练与留出，再只在训练折拟合标准化、特征选择和模型；同session各段始终一起分组。窗口与会话聚合分别报告，不换较好口径掩盖逐窗误判。

缺独立会话时只报告可训练或训练回放。内部同台架留出不等于独立重装、跨设备或新工况泛化。更换任务重新选特征/模型/指标；明确feature schema和mask，兼容解析不等于旧模型适合新特征。

模型元数据应包含schema、特征mask、归一化、参数、配置与采集/滤波/FFT/setup身份、训练源SHA/session、provenance。验证结果与实际模型字节SHA绑定；本公开候选不附真实训练模型、采集会话或模型身份。分数不自动是校准概率。

对缺/坏CRC、不连续、不完整、非有限等输入明确失败；模拟源必须声明，不能冒充机械来源。削顶/饱和如何影响可用性由任务规格决定。使用自己的CLI前先看其--help和目标设备契约，输出写新路径，不覆盖原数据或模型。

方法案例见[e06](evidence.md)。本候选没有训练或机械指标，单元测试不能产生检测准确率。
