# 用最小证据定位跨 PL/PS 工程故障

从观察点向相邻层缩小范围，不以替换整个系统作为默认第一步。
适用于采集、总线、信号处理、模型、UI和部署；当前振动项目不是唯一目标。
每次保留失败输入与版本，避免“修好后”失去可复查的反例。

## 输入与输出契约

输入：精确现象、发生条件、源/产物身份、日志、代表输入及预期输出。
输出：最小复现、竞争假设、区分试验、修复及同条件回归。
尚不能复现时先补观察，不伪造确定原因。
把每个假设标为待检、支持或排除，说明证据依据。

最小记录：
`observed, expected, input_sha, config, source_revision, artifact_sha, environment`。
再写 `hypotheses, discriminating_check, result, change, regression, remaining_unknowns`。
敏感身份留本地；公开报告可使用稳定代号与所需的非敏感摘要。

## 四步缩小范围

1. 确认观察是否可靠：数据、日志、时钟和运行版本来自当前作业吗？
2. 在最近的模块边界取一份可独立验证的输入/输出。
3. 保持输入、配置和计时范围相同，只改变能区分假设的因素。
4. 修复后重跑原反例及邻近边界，保留原失败和修复后结果。

不要把一次重试成功改写为原检查成功。
不要先放宽容差、移除断言、忽略坏帧或重命名模型来让流程继续。
环境因素可通过隔离检验，但原环境失败依旧属于观察事实。
没有硬件访问时可缩到主机/仿真，板端假设保留未知。

## 数据链与存储

| 现象 | 先比较的证据 | 下一步判据 |
|---|---|---|
| 图平滑而频谱跳变 | 原码序号/时间戳、CRC、窗与预览来源 | 原码连续则查分析边界；否则先修采集/缺口策略 |
| 文件存在但尾段缺失 | 接收、排空、封段、发布事件与最终长度 | 区分停止请求、写入与真正发布 |
| 通道数改变后错位 | 帧跨度、packed/padded、字节序和通道表 | 用不同通道标记的合成帧定位索引 |
| 慢UI导致丢原码 | 队列上限、存储等待和预览背压 | 独立可丢预览后原码应保持相同或明确降级 |
| CRC全部失败 | 多项式/反射/初值/覆盖字节、原字节 | 先用已知测试向量，不能默认忽略CRC |
| 时间差异常 | 采样/接收时钟、回绕/复位与单位 | 不用接收时间补成均匀采样 |
| SHA账本全错 | 编码、行尾、传输方式和真实字节 | CRLF/LF不同仍是不同文件，不先断言介质损坏 |

合成数据用于制造边界，真实设备数据用于验证实际通路；两者分开标记。

## PL 数值、接口与资源

| 现象 | 最小区分试验 | 修复后门槛 |
|---|---|---|
| FIR输出偏一拍 | 极小脉冲、首个完整历史点、抽取相位 | 黄金参考与RTL的支持区间一致 |
| 对称优化后极值错 | 满幅同号/反号对，观察预加法位宽 | 不因省位改变舍入/饱和语义 |
| FFT峰位置/幅值错 | DC、单bin正弦、复输入和指数 | 核实自然/位反序、缩放、窗校正 |
| 单正弦弱频带未通过 | 既有量化floor与目标必需指标 | 保留not_evaluated，另用明确合成多频覆盖 |
| 背压时重复/丢数据 | READY间歇及作业边界 | stalled VALID/payload稳定，计数和TLAST一致 |
| 资源降了但整机没快 | prepare/搬入/核/搬出/consume分段 | 结果先一致，再比较同范围延时 |
| 时序摘要无数字 | 原始rpt、表头、器件与构建身份 | 未知格式失败，不补旧数字 |
| Available被当Used | 完整资源表头/列序和语义 | 不按单行位置猜列 |
| 不同器件也“通过” | 两份报告完整器件标识 | 不匹配明确拒绝或分开报告 |
| 端点数字矛盾 | 每类失败数、总数及报告含义 | 自相矛盾保留失败，不以WNS覆盖 |

DSP/LUT/FF/BRAM的变化只能在匹配目标/约束/工具和真实报告下比较。
暂未实现的流水/DMA/位宽方案写为提议，不当作已有收益。

## PS 与模型

| 现象 | 先查什么 | 合法结论/动作 |
|---|---|---|
| 训练很好而新数据差 | 同源/重叠跨split、组层级、scaler拟合范围 | 按组重划后重训；组不足就报告不足 |
| 文件能读但预测异常 | 特征顺序/单位、采样配置、模型SHA | schema不兼容拒绝，不靠重命名兼容 |
| 旧转速参考不匹配 | 运行算法、合法输入和旧schema | 由任务确定工况量是否合法，不沿用旧门控 |
| 加一类后模型失效 | 类别映射、输出维度、unknown策略 | 升级制品schema并重做评估 |
| 指标与部署不对应 | 模型、ELF/容器、数据清单与评估身份 | 重新绑定实际制品，不沿用旧模型数值 |

元数据清单的审计能定位常见泄漏，不能独立证明标签真实或目标域充分。
训练回放和调参结果不变成最终独立测试。

## UI 与目标环境

| 现象 | 区分试验 | 复验边界 |
|---|---|---|
| 无数据无法设量程 | 检查整体面板禁用与动作依赖 | 只禁需要数据的动作 |
| 刷新后固定Y消失 | 查paint、模式切换和配置键 | 刷新/切通道/重开均保留语义 |
| 设置已写但重启丢 | 实际配置根、文件内容与挂载 | 写入/重开/软件重启/掉电分别验收 |
| GUI仅某后端失败 | 隔离Xvfb/xcb/XDG与缩放 | 保留原失败；隔离成功不等于实板通过 |
| 新板启动旧程序 | 当前启动链、载荷位置和运行身份 | 用该板实际布局，读回不等于运行 |
| 同型号板SD布局不同 | 当前介质/分区/挂载/容量 | 板专属计划，不格式化未知数据 |

主机自动化手势不是实际手指，正常重启不是断电冷启动。
目标未知或暂停板测时，不使用“排障”作为恢复写板的理由。

## 可直接使用的排障提示词

```text
按此Skill定位[现象]，先不假定原因。
预期：[具体输出]；实际：[日志/文件/测量]；输入SHA：[值]。
源/运行载荷：[版本]；配置/环境：[事实]。
允许操作：[只读/隔离复现/指定目标变更]。
列最多三个有证据依据的竞争假设；
先做成本最低且可区分假设的检查，不跳过现有断言。
每步输出观察、支持/排除、仍未知与下一步。
修复后重跑原反例和邻近边界，分开合成/仿真/板端证据。
```

## 何时停止扩大排查

已找到满足任务验收的最小修复后，不无故重构无关层。
无法获得关键输入、目标身份或复现环境时，列明阻塞的具体结论。
未知不等于失败原因；策略拒绝也不自动等于文件锁或Windows权限。
经验反例与来源见 [evidence.md](evidence.md)，CLI合成结果见 [examples/validation/](../examples/validation/)。
