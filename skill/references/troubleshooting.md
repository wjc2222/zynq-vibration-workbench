# 从观察缩小故障

先记录确切输入/版本、现象、预期与实际、日志和哈希。只读复现优先；一次只改相关环节；保留失败，不把重试成功改写为原检查成功。

| 现象或失败观察 | 最小诊断与修复 | 复验/失效条件 | 来源 |
|---|---|---|---|
| 图顺滑但频谱/检测跳变 | 查raw index/tick/CRC/session，确认是否误送抽稀预览；gap作废重热，封段BIN独立重开 | 连续完整窗才可分析；换协议重新适配 | e02 |
| 量程设置不了或刷新后恢复auto | 查空数据整体禁用、每次paint自动缩放和模式配置键；只禁依赖数据的控件，持久fixedY | 无数据、刷新、切模式、换通道、重开分别验证 | e07 |
| 设置写入但掉电后丢 | 查实际QSettings落点及可写持久根，不按HOME猜 | 写入/重开/重启/掉电分层，未测不得合并 | e01/e07 |
| RPM数值正常仍判“参考不匹配” | 先辨认旧参考schema与当前监督模型；不能把旧模型重命名成新模型 | 先核当前模型是否允许RPM/PPR/order输入；坏数据约束保留 | e06 |
| 训练显示很好而新采样差 | 检查同session分段/副本/重叠是否跨训练测试，scaler是否用到测试数据 | 整session重划，训练折独立标准化；数据不足报告不足 | e06 |
| 模型/验证指标和运行软件对不上 | SHA绑定ELF、模型、schema、mask、验证文件和数据配置 | 不兼容明确失败；新报告不得沿用旧模型数值 | e01/e06/e08 |
| 新板SD空间或启动路径不对 | 查当前CID/MBR/mount/容量和U-Boot链，禁止套旧两分区publisher | 新建板专属适配；保护原文件和回滚；不格式化 | e01/e08 |
| 单正弦严格频带比较不通过 | 查看是否弱必需带低于既有floor；保留not_evaluated/quantization_limited | 不放宽既定验收阈值，用合成多频输入覆盖任务定义的全部指标；仍非机械准确率 | e04 |
| SHA账本“全错”而payload看似一样 | 查传输编码/CRLF和字节哈希，不先归因SD损坏 | 保留原失败，用明确LF账本复核；不能默认忽略行尾 | e01/e08 |
| GUI测试仅WSLg/offscreen失败 | 隔离Xvfb/xcb、XDG配置复验，并核对是否环境差异 | 保留原失败；主机测试不替代实板触摸 | e07 |
| Vivado摘要缺数字 | 打开原rpt检查格式、构建身份；未知格式扩展解析器前先有真实样本/反例 | 解析失败退出，不能用上次结果补字段；CDC/DRC另检 | e03 |
| 摘要把Available当Used、不同器件也成功或端点数自相矛盾 | 先核完整资源表头及列序、两份器件身份、每类失败端点≤总数；不按数据行位置猜语义 | 原独立测试4失败原样保留，修parser并按不变断言复验；未知别名失败 | 本次独立前向测试 |

字节身份案例：文本行尾CRLF与LF不同会导致SHA不同，不能直接归因存储损坏。先保留原失败，再以明确的编码/行尾复验。当前公开合成回归见[结果](../examples/validation/results-public.json)，私人旧日志不随候选公开。
