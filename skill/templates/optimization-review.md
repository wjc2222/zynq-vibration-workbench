| 变化候选 | 保持的语义 | 可能收益 | 代价/失效风险 | 状态与证据 |
|---|---|---|---|---|
| 对称FIR预加法 |  | 乘法项减少 | 预加法需扩位、舍入顺序 | proposal |
| 核复用/共享FFT |  | 减少重复核 | 排队、缓冲、窗口身份 | proposal |
| 更多流水 |  | 缩短组合路径 | FF/延时/valid对齐 | proposal |
| 存储bank/双缓冲 |  | 端口/吞吐改善 | 冲突、所有权和缓存 | proposal |
| 批量传输或DMA |  | 降低搬运开销 | 缓存一致性、驱动和恢复 | proposal |
| 位宽压缩 |  | 资源/带宽减少 | 量化和溢出预算 | proposal |

删去不相关行，选最小且能验证瓶颈的变化。
对称FIR的逻辑乘法减少不自动等于DSP数量减半。
共享核资源更少也不自动满足最坏时延；核更快也不自动改善完整API。
AXI-Lite送料的现有工程不能仅因提出DMA而称为自主流式实现。
